# Interface demonstrativa inspirada na captura enviada

Recriação front-end em HTML, CSS e JavaScript puro, responsiva e sem dependências externas.

## Executar
1. Extraia o ZIP.
2. Abra `index.html` no navegador (ou use a extensão Live Server).

## Interações incluídas
- Seleção e remoção de odds no cupom de apostas.
- Alternância entre cupom e minhas apostas.
- Seleção de categorias esportivas.
- Faixas demonstrativas no Bet Mentor e entrada de valor.
- Botões de login/cadastro com feedback demonstrativo.
- Deslocamento horizontal das promoções.

Os jogos, odds e textos são dados fictícios/ilustrativos para prototipagem. Não há backend, autenticação ou integração com serviços reais.
